Running the Servers

To test the authentication system, you can run one of the following commands:

Minimal Test Server

node minimal-server.js

Provides a basic health check and status page on port 5000.

Authentication Test Server

node basic-server.js

A standalone server that demonstrates the authentication system with login, register, and session management on port 5000.

Production Server

npm run build && npm run start

Builds and runs the complete application in production mode on port 5000.
